# ADR-0007: 오프라인 G1 수용과 판정 문맥 경계

- 상태: 로컬 개발 범위 채택. 운영·배포·실제 통신 수용과 분리한다.
- PRD 원문 v1.1 불변. 개발 인터페이스 계약은 `g1-1.1.2`, 결과 schema는 `1.1`이다.

## 결정
1. G0의 안전 개발 선택은 x64, 현 개발 호스트에서의 로컬 시험, 오프라인 기본, 마스킹 기본 ON, 외부 기설치 Npcap 선택 어댑터, 미서명 개발 빌드로 한정한다. 다른 Windows/Server 지원, 라이선스 검토, 코드 서명, 설치·제거 및 두 VLAN 실측을 완료로 간주하지 않는다.
2. G1은 데이터 모델·오류 분류·레지스트리/DAG·JSON Schema·구버전 변환·합성 fixture의 오프라인 검증 게이트다. 선택 UI의 컴포넌트/타입/빌드 검증은 포함하되 브라우저 실측·네이티브 IPC·통신 엔진 연결이 완료되었다고 주장하지 않는다.
3. 구버전 원본에 없는 로컬 시간대와 host 역할은 `null`이다. UTC 표기 시작 시각이나 `client-A` 같은 alias에서 로컬 시간대/역할을 추정하지 않는다. 원본 JSON과 변환 설명을 보존한다.
4. OS 오류 10054는 `RESET`, 11002/11003은 `DNS_ERROR`로 분류한다. 근거는 수집된 Microsoft Winsock 문서 `.harness/references/winsock-errors.txt`와 독립 컴파일 probe의 기존 오분류 재현 결과다. RESET은 OS가 보고한 연결 재설정이며 RST 패킷 캡처 또는 응답 생성 장비를 확인했다는 의미가 아니다.
5. 긍정 사실 판정의 단정·증거 검사는 `Finding.statement`에 적용한다. `limitations[]`/`next_checks[]`는 문자열·형식 검증을 유지하되, 금지 판정의 인용·가설·확인 요청 자체를 긍정 관찰로 해석하지 않는다. 다른 곳의 부정어로 실제 statement의 거짓 확정을 통과시키는 것은 계속 거부한다. 문구 가드는 증거 파일의 진위나 모든 자연어의 의미를 인증하는 수단이 아니며, G6 보고서는 검증된 고정 템플릿과 원본 출처를 사용하고 입력 텍스트를 사실로 승격하지 않아야 한다.
6. 현재 CLI 전역 자동 승인 상태는 기존 설정이다. FILE ONLY 지시·worktree·경로/도구 감사는 작업 통제이며 OS 강제 파일/네트워크 격리라고 표현하지 않는다.
7. 로컬 HTTP·브라우저 검증은 승인 시간 초과로 보류되었다. 새 명시 승인 전 다른 명령/도구/기동 모드로 우회하지 않는다. 실제 진단망 시험도 보류하며 G2 실행·수용을 선언하지 않는다.

## 검증 근거
- 최신 실제 수치·명령 종료 코드·소스 해시: `artifacts/g1-gate-report.json`.
- 최초 스키마 실패, Winsock 오분류, 제한사항 오탐 및 Clippy 실패 로그는 삭제하지 않고 로컬 artifacts에 보존한다.
- 단위 시험과 독립 probe 수치를 별도로 기록한다. 반복·교차 검사를 합쳐 전체 기능 완료 비율처럼 표현하지 않는다.
- 전체 P0/설치/운영 DoD는 미완료다. 로컬 G1 통과는 후속 기능·운영 승인·배포 승인이 아니다.
