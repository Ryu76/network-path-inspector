# ADR-0006: 보고서 기본 마스킹 ON, 허위 익명성 보장 금지, 오프라인 병합 기본 및 증거 출처 분리

- 상태: Accepted
- 작성일: 2026-10-20
- 관련 요구사항: PRD 1.2, 4.2, 4.3, 6.3, 7.2, 8, 14.4, 16.3, 16.4; `contracts/g1-interface-contract.json`

## 1. 배경 및 문제 (Context)
- `PRD.md` 8절(보안·운영 정책) 및 16.3~16.4절은 1) 기본 보고서의 내부 IP/호스트명 마스킹 정책, 2) 원본 PCAP/로그 반출 시 보안 경고, 3) 양방향 진단의 기본 통신 방식(오프라인 vs 온라인 관리 서버)을 확정하도록 요구한다.
- 또한 텍스트 보고서에서 IP 문자열을 마스킹하더라도, 함께 반출되는 PCAP 바이너리나 서브넷 구조, 포트, 시퀀스, 시간대 정보를 통해 내부망 환경이 유추될 수 있으므로 사용자에게 "완벽한 익명성"을 보장한다는 식의 허위 안내를 해서는 안 된다.
- 아울러 원본 증거와 정규화 데이터, 테스트용 합성 픽스처(`synthetic`), 미확인 시계 오차(`clock_offset_ms`)의 표기 규칙을 명확히 고정해야 한다.

## 2. 결정 (Decision)
1. **기본 보고서 마스킹 ON 및 허위 익명성 보장 금지**:
   - 보고서(PDF 및 요약 출력) 생성 시 내부 IP 주소, 호스트명(`host_alias`), 민감 패킷 페이로드에 대한 **마스킹 옵션을 기본값 ON**으로 설정한다.
   - 원본 증거(PCAPNG 파일, 원본 시스템 스냅샷 및 측정 JSON)는 로컬 스토리지에 비공개(private)로 보존한다.
   - 사용자가 보고서 또는 원본 증거가 포함된 ZIP 번들을 외부로 내보내기(Export)할 때는 반드시 **개인정보 및 내부망 토폴로지 노출 가능성에 대한 명시적 경고(Explicit Export Warning)** 를 표시하고 사용자 확인을 거친다.
   - UI와 보고서 어디에서도 **"마스킹을 통해 완전한 익명성이 보장된다(False Anonymity Guarantee)"는 허위 문구를 사용하지 않으며**, 원본 PCAP 반출이나 트래픽 메타데이터를 통해 호스트가 식별될 수 있음을 경고문에 명시한다.
2. **오프라인 병합(`paired_offline`) 기본 및 인바운드/클라우드 연결 금지**:
   - 양방향 진단은 파일 기반 **오프라인 결과 ZIP 병합(`paired_offline`)을 기본 모드**로 확정한다.
   - 클라이언트와 서버 어느 쪽에서도 인바운드 관리 포트를 열거나 웹서비스를 구동하지 않으며, 클라우드나 외부 서버로의 자동 업로드 기능을 두지 않는다.
   - 온라인 관리 서버(P1)는 G0~G8 범위에서 보류(Deferred)한다.
3. **원본·정규화 분리, 합성 픽스처 라벨링 및 미확인 시계 오차 `null` 처리**:
   - 원본 수집 파일(raw capture/input, 구버전 v1.0 원본 JSON)과 정규화된 분석 데이터(`session.json`, `measurements.jsonl`)는 항상 별도 파일/필드로 분리 보관하며 원본을 덮어쓰지 않는다.
   - 모든 `Evidence` 항목은 `synthetic: boolean` 필드를 필수로 가지며, 테스트 픽스처(`synthetic: true`)는 어떠한 경우에도 실제 측정 결과(`synthetic: false`)로 둔갑시키지 않는다.
   - 양방향 시계 오차(`clock_offset_ms`, `clock_uncertainty_ms`) 및 자원 사용량(`resource_metrics`)이 측정되지 않았거나 알 수 없을 때는 숫자 `0`으로 채우지 않고 반드시 `null`로 유지한다.

## 3. 결과 및 영향 (Consequences)
- 외부 방화벽 업체에 보고서를 전달할 때 의도치 않은 내부망 정보 유출 위험을 줄이면서도, 원본 증빙이 필요한 경우 명확한 보안 경고 하에 재현 가능한 데이터를 전달할 수 있다.
- 합성 데이터 혼입이나 `0ms` 시계 오차 오판 없이 증거의 출처(Provenance)와 무결성을 끝까지 추적할 수 있다.
