# Network Quick Check 위협 분석 및 보안 원칙 (QG0)

## 1. 실행 권한 및 프로세스 격리
- **`asInvoker` 매니페스트 한계**: `asInvoker`는 시작한 부모 프로세스의 토큰을 그대로 상속하므로, 관리자 권한 프로세스에서 실행 시 자동으로 일반 사용자로 강등되지 않음.
- **권한 상승 미요구**: 앱은 UAC 승격을 요구하지 않고 일반 사용자 권한 실행을 목표로 함. 이미 상승된 부모 프로세스로부터 권한을 상속받더라도 OS 정책, 방화벽, 라우팅 테이블, 레지스트리, 인증서 저장소를 일체 변경하지 않는 운영 무변경 원칙을 엄격히 준수.
- **비파괴 측정 원칙**: 드라이버/서비스 설치, Npcap 연동, DB 인증/SQL 쿼리 실행, 관리자 권한 우회 시도 일체 배제.

## 2. 네트워크 안전성 및 비인가 탐색 방지
- **대상 범위 제한**: 사용자가 명시적으로 입력한 대상(최대 100건)에 대해서만 단일 연결 시도 수행.
- **탐색 행위 금지**: 포트 스캔, 서브넷 대역 무단 탐색, 자동 백그라운드 스캔 등 운영망에 영향을 주는 행위 일체 금지.
- **안전 기본값**: 동시성 상한 4, TCP 타임아웃 기본 3000ms를 적용해 부하 방지.

## 3. 개인정보 보호 및 데이터 유출 방어
- **PII 노출 경고**: 결과 공유/내보내기 전 로컬 IP, NIC 식별자, 호스트명, 원시 OS 메시지(사용자 계정명, 내부 경로 노출 가능) 포함 여부를 명시 경고.
- **외부 유출 차단**: 네트워크를 통한 원격 자동 전송 및 클라우드 업로드 기능 없음.
- **CSV 수식 주입 방어**: CSV 내보내기 시 셀 시작 문자(`=`, `+`, `-`, `@`)에 대해 이스케이프 처리를 적용하여 스프레드시트 실행 공격 방지.
- **관련 문서**: [인터페이스 계약](../../contracts/quick-check-interface-v0.1.json) 및 [PRD v1.2](../requirements/Network_Path_Inspector_Harness_PRD_v1.2.md)의 보안 요구사항 준수.
