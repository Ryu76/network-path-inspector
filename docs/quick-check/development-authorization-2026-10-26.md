# 2026-10-26 사용자 승인: GUI 병행·Windows 배포 목표 확대

## 직접 승인 및 해석
- 사용자는 개발 순서를 부모 감독자에게 위임하고 GUI 병행 개발을 명시 승인했다.
- 지원 목표는 Windows 10, Windows 11, Windows Server 2012 이후 전체 버전이다. 이는 사용자 목표이지 현재 바이너리의 호환성 보장이나 시험 완료 판정이 아니다. 미래에 출시되는 버전의 무조건 지원도 보장하지 않는다.
- 시험 환경에 대해서는 '없음'과 '있긴한데 하긴 귀찮아 너가 다 해줘'가 함께 전달됐다. 실제 접근 대상/관리 수단/격리 여부는 제공되지 않았다. 따라서 사용자가 직접 시험을 맡지 않아도 되도록 자동화하되 임의의 운영 장비·네트워크를 선택하지 않는다.
- 사용자에게 암호/토큰을 채팅으로 요구하거나 원격 접속 정보를 추측하지 않는다.

## 변경된 개발 순서
1. 기존 수용 근거와 공유 코어/Inspector 보호를 유지한다.
2. QG2 실환경 미검증을 그대로 남기고 QG3의 네이티브 GUI 상태모델·입력 관리·기능 선택부터 작은 단위로 병행한다.
3. 기존 CLI/DNS worker 계약을 보존하며 GUI 워커·결과 전달·취소를 순차 연결한다. UI 스레드에서는 네트워크 I/O를 수행하지 않는다.
4. 현재 접근 가능한 로컬 시험은 감독자가 자동화한다. 설치/상승/정책 변경이 필요한 시험 인프라 구축은 별도 승인 범위로 남긴다.
5. QG2를 통과했다고 기록하지 않으며 후속 GUI 부분 수용을 전체 QG3 또는 제품 수용으로 확대하지 않는다.

## 지원 목표 및 확인된 호환성 경계
- 현재 도구 확인: rustc 1.98.0, 설치 target은 x86_64-pc-windows-msvc 하나다. 따라서 첫 구현은 기존 x64 구성에서 수행하되 사용자가 x64 전용을 승인했다고 주장하지 않는다.
- Rust 공식 windows-msvc 문서는 Windows 10 / Windows Server 2016 이상을 요구한다. 따라서 Server 2012 및 2012 R2는 현재 표준 target의 보장 범위 밖이다. 현재 EXE가 작동한다고 주장하지 않는다.
- 공식 win7-windows-msvc 대안은 Tier 3이며 미리 빌드된 표준 라이브러리가 배포되지 않는다. 별도 호환 빌드 가능성은 조사 대상이지 설치/빌드/지원 승인 사실이 아니다.
- 구형 호환 목표 때문에 기존 공유 엔진을 임의 다운그레이드하거나 전체 Rust toolchain을 바꾸지 않는다. static CRT도 OS API 호환성을 대신하지 않는다.
- Server Desktop Experience와 Server Core 실행 환경은 별도로 분류하며, GUI가 없는 환경을 지원 제외로 확정하지도 GUI 실행 가능으로 단정하지도 않는다.
- 원문 PRD는 보존한다. 이 문서는 기존 Server 2016+ 후보 범위와 QG2 선행 개발 순서에 대한 새로운 사용자 목표/승인을 덧붙이는 기록이다.

## 유지되는 안전·검증 경계
- 실제 네트워크 시험 자동 실행은 부모가 소유한 literal 127.0.0.1/::1 및 해당 보유 포트만 허용한다.
- 운영망/운영 DB 접근, 임의 원격 접속, 스캔, 방화벽/route/registry/인증서 변경, 관리자 상승, 드라이버 설치를 승인받은 것으로 해석하지 않는다.
- WebView/Npcap/Agent/PDF/SQLite를 Quick Check에 포함하지 않는다.
- FILE ONLY writer는 전용 worktree와 정확한 허용 파일 범위로 격리한다. 부모 감사·독립 QA·실제 시험 뒤에만 선택 통합한다.
- Inspector baseline61 원본, 원본60 불변 및 기존 승인 pub4byte 예외1을 보존한다.
- 기존 최신 검증은 2026-10-23 root454PASS/0FAIL/31ignored이다. 이전 native31PASS는 역사 증거이며 이번 승인 기록을 새 테스트 통과로 세지 않는다.

## 현재 시작한 작업
- 독립 읽기전용 GUI 첫 구현 단위 설계와 Server 2012/2012 R2 소스 호환성 분석을 병렬 요청했다: deleg_796f094f.
- 아직 새 GUI 구현/빌드/실행 수용은 하지 않았다. 분석 결과를 검토한 뒤 좁은 FILE ONLY 구현 단위로 진행한다.
